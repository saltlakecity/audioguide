02 / ПРЕЗЕНТАЦИЯ

Открой презентацию в режиме показа, затем выбери её окно.

«Слайд N» — номер + Enter, как в PowerPoint. «Следующий» / «Предыдущий» — стрелки, если приложение их поддерживает. Команда отправляется только активному выбранному окну.

03 / ПОКАЗ

Микрофон выключен.
Ctrl + Alt + Пробел — остановка из любого окна. Можно свернуть пульт, речь продолжит обрабатываться.

МОЙ МАРШРУТ

Если ты вручную переключил слайды, поправь «Текущий слайд». Это ограничитель переходов, пульт не читает содержимое презентации. Сходство — оценка модели, не вероятность.
